# BLUE07 → GREEN31-GREEN35 展开审计 v1.0

状态：PASS

## 审计目标

本轮只展开 `BLUE07｜汽车人、霸天虎与赛博坦内战`，不得回写 BLUE06 的战力规则，不得提前定义 BLUE08 的宇宙遗产权限，也不得替具体角色预设阵营结局、军衔或历史战役结果。

## 现行展开

- GREEN31｜阵营核心价值与政治路线
- GREEN32｜加入动机、阵营归属与成员身份
- GREEN33｜指挥链、军纪与命令边界
- GREEN34｜叛离、转阵营、投降与赎罪
- GREEN35｜战争伦理、平民与占领边界

## 职责边界检查

### GREEN31

PASS。只负责两大阵营的政治路线与力量观。已明确个体复杂不等于阵营路线没有道德差异，也没有将汽车人写成天然正确或将霸天虎成员写成天生邪恶。

### GREEN32

PASS。只负责加入、留队与阵营身份形成原因。已区分自愿认同、环境卷入、利益依附与被迫征召，并明确阵营徽记不能单独替代人格判断。

### GREEN33

PASS。只负责一般指挥、军纪、抗命与责任边界。未建立具体军衔表或部队编制；已明确服从命令不能完全取消个人责任。

### GREEN34

PASS。只负责叛离、转阵营、投降与重新建立信任。已明确换旗不自动洗清过去，赎罪需要持续行动与承担后果；同时保留个体真正改变的可能。

### GREEN35

PASS。只负责平民、医疗人员、失能者、俘虏、占领与附带伤害边界。已明确总体战争不等于所有目标合法化，人类平民同样受这一原则约束。

## 跨条目一致性审计

PASS。

- GREEN31 与 BLUE07 上位政治路线一致，不做虚假双方等同。
- GREEN32 与 GREEN34 保持身份连续性：加入原因可以复杂，但后续自主选择仍产生责任。
- GREEN33 与 GREEN35 保持一致：明显要求屠杀平民或永久奴役无辜者的命令不能因“上级命令”自动获得正当性。
- GREEN34 与 BLUE02/GREEN06 的个体连续性一致：转阵营改变政治归属，不改变过去发生过的行为与责任。
- GREEN35 与 GREEN01-GREEN04 的地球社会和战损规则一致，重大军事行为必须留下现实社会后果。

## 政治与角色复杂度审计

PASS。

本组明确保留阵营路线的真实差异，同时允许成员拥有不同出身、动机、派系、私人关系与改变空间。不得把“复杂”写成“双方行为无差别”，也不得把阵营标签替代具体角色选择。
