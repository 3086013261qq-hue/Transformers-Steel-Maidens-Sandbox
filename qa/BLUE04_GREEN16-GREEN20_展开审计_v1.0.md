# BLUE04 → GREEN16-GREEN20 展开审计 v1.0

状态：PASS

## 审计目标

本轮只展开 `BLUE04｜火种能量与专属武装系统`，不得覆盖 BLUE02 的生命代谢与常规医疗，不得回写 BLUE03 的身体文化，不得侵入 BLUE05 的载具变形、BLUE06 的综合战力判定、BLUE07 的阵营军制或 BLUE08 的宇宙遗物权限。

## 现行展开

- GREEN16｜武装器官展开与战斗形态
- GREEN17｜专属武器谱系与战术定位
- GREEN18｜能量供给与控制链接
- GREEN19｜有限拆离、回收与失落后果
- GREEN20｜冷却、过载与武装损毁

## 职责边界检查

### GREEN16

PASS。只负责从生理结构进入战斗结构时的连续机械展开、部署速度、锁定状态与受损失败。没有规定具体角色武器，也没有把展开动作等同于载具变形。

### GREEN17

PASS。只负责专属武装的功能谱系与战术定位。已明确武器类型不是统一强弱等级，民用个体可以拥有工程、医疗、牵引等非军用武装潜力；具体综合强弱仍归 BLUE06。

### GREEN18

PASS。只负责武装供能链、控制链、身份识别与远程控制边界。Energon 的日常生命代谢仍由 GREEN07 负责，本条只讨论进入武装系统后的战斗供能与控制关系。

### GREEN19

PASS。只负责可分离武装的拆离、回收、夺取、损毁和重新接驳。已明确拆离并非全员共有能力，分离武装仍属于本人身体系统，敌人夺取后也不能自动获得原主人完整性能。

### GREEN20

PASS。只负责热负荷、冷却、保护切断、过载与累积损伤。已明确解除限制等于主动放弃安全余量，不是免费强化；极限输出后的损伤不会在下一轮自动恢复。

## 跨条目一致性审计

PASS。

- GREEN16 与 GREEN14 保持职责分离：GREEN14 说明武装器官首先是身体，GREEN16 才说明其如何进入战斗形态。
- GREEN18 与 GREEN07 保持职责分离：GREEN07 负责维生代谢，GREEN18 负责武装供能与控制。
- GREEN19 与 BLUE03 的身体自主权一致：拆离、失窃和强制改装都具有身体意义。
- GREEN20 与 BLUE06 的战力规则一致：过载能够暂时提高表现，但会通过能源、伤势和系统状态反过来影响后续战力。
- 本组没有引入固定数值等级、无代价无限弹药、无限远程操控或自动恢复。

## 关键词审计

PASS。

- 不使用 `武器`、`能量`、`拆离`、`过载` 等单个宽泛裸词作为唯一触发词。
- GREEN16-GREEN20 使用多词组语义关键词，降低同组误触。
- `active_green_entries.keywords` 继续作为正式装配时唯一有效关键词来源。

## 战斗风格审计

PASS。

本组保留《变形钢姬》的核心视觉：武装来自身体，展开是连续机械运动，战斗输出有供能链与控制链，极限状态有真实代价。武装器官既不是普通外挂装备，也不是可以凭剧情无限提升的魔法炮台。

## 结论

BLUE04 已完成第一轮正式绿灯展开。

本轮不修改 BLUE01-BLUE08 正文，不提前展开 BLUE05 的扫描与载具变形细节。
