## 四、心理模型去同质化

PASS。

- 斯汀嘉：被定义为仿制与替代 → 极端竞争 → “复制品”评价 → 建立独立身份。
- 琼希普：可拆分机体被当耗材 → 多角度控制 → 子体被当独立零件 → 维护同一人格连续性。
- 莫霍卡：小型单位被轻视 → 疯癫挑衅 → 体型羞辱 → 不靠制造恐惧也被认真看待。
- 德蕾德：残破机体被当废品 → 暴力证明价值 → 拆件/废品化评价 → 残破仍被承认有价值。
- 妮特萝·宙丝：战机平台可替代感 → 炫耀与抢注意 → 被说普通 → 作为具体个体被记住。
- 昂斯萝特：计划失败后被归罪 → 过度控制与部署 → 擅自脱离计划 → 被允许调整而非永远正确。
- 贝瑟琪：被囚禁成危险装备 → 抢先暴力 → 强制束缚 → 在承认危险的同时仍被当作完整生命。

四槽均完整保持 `Trauma → Defense → Trigger → Need`。
