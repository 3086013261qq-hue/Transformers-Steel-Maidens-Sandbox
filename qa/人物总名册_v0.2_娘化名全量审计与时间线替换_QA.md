## 一、时间线命名规则纠正

PASS。

旧表述容易被理解成“正式时间线继续使用原名，只靠映照辅助人物卡”。本轮正式纠正为：

1. `原名映照` 只用于原作检索、资料核对、事件对齐与替换键；
2. 正式五部电影时间线中的赛博坦人物名称必须替换为娘化名；
3. `<world_timeline>` 的事件标题、正文、角色参与者字段都遵循这一规则；
4. 原作中文名 / 英文名只允许留在 QA、资料索引、替换映照文件与原作核对记录；
5. 多别名同一角色必须汇入同一个娘化名。

关键例：

- 擎天柱 / Optimus Prime → 何博玟
- 威震天 / Megatron / 惊破天 / Galvatron → 薇震天
- 幻影 / Dino / Mirage → 米拉琪
- 千斤顶 / Que / Wheeljack → 薇尔嘉
- 堕落金刚 / The Fallen / Megatronus Prime → 梅格萝娜

为后续时间线自动替换新增：

`manifest/character-name-replacements.v1.json`

## 二、命名审计标准

本轮不采用“全部重命名”的机械返工方式，而按以下标准逐条判断：

- 女性感与赛博坦角色感同时成立；
- 读起来像角色名，而不是临时机器翻译；
- 不依赖统一追加“姬、娘、娜”等后缀制造女性感；
- 核心角色之间避免高混淆近音；
- 原本就是女性身份的 Arcee、Chromia、Elita-One、Quintessa 保留正式名；
- 已由用户锁定的何博玟、薇震天绝不改动；
- 名字无需强行与原名一一谐音，因为原名映照与替换 manifest 已承担检索职责。
