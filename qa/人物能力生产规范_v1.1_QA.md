# 《变形钢姬》人物/能力生产规范 v1.1 QA

状态：PASS / FORMAT_LOCKED

## 结论

本轮在保留咩咩制卡包·全栈人物骨架、心理模型和能力拆分逻辑的前提下，将容易诱发“人类女性外观幻觉”的九个外貌字段替换为赛博坦原生字段。

## 外貌字段一一替换

- 发色 → 头部主色
- 发型 → 头部结构
- 瞳色 → 光学镜
- 身材 → 机体比例
- 胸部 → 胸甲结构
- 上衣 → 上身装甲
- 下装 → 下身装甲
- 配饰 → 外置结构
- 鞋子 → 足部结构

PASS：字段数量未增加，位置关系保持一致；模型不再被“发型/上衣/鞋子”等词诱导去虚构毛发、布制服装或高跟鞋。

## 咩咩核心结构保留

PASS：

- 名字
- 性别
- 印象
- 心理模型
- 对话范例

均保留原职责。

心理模型严格保持：

1. Trauma
2. Defense
3. Trigger
4. Need

固定顺序，无新增第五槽，无赛博坦化改名。

## 体格字段检查

PASS：

- `机体比例` 必须承载身高、质量/体重、机体规格、肩腰胯与肢体比例；
- `胸甲结构` 必须保留字母罩杯等效视觉体量；
- 不得将体型或罩杯直接等同于战力。

## 能力拆分检查

PASS：能力继续使用 `<核心设定:角色名·能力>`，不进入人物外貌字段。

## 时间线检查

PASS：正式剧情与 `<world_timeline>` 继续只输出娘化名，原名仅作为工程检索与映照键。

## 废弃项

从 v1.1 起，正式人物条目不得继续使用以下字段：

`发色 / 发型 / 瞳色 / 身材 / 胸部 / 上衣 / 下装 / 配饰 / 鞋子`

如在后续正式人物条目中发现这些字段，QA 直接判 FAIL。
