# BLUE05 → GREEN21-GREEN25 展开审计 v1.0

状态：PASS

## 审计目标

本轮只展开 `BLUE05｜变形、扫描与载具拟态`，不得覆盖 BLUE02 的常规医疗与生命代谢，不得回写 BLUE04 的专属武装供能与过载，不得侵入 BLUE06 的综合战力、BLUE07 的阵营制度或 BLUE08 的宇宙遗产。

## 现行展开

- GREEN21｜扫描模板获取与兼容边界
- GREEN22｜结构映射与形态连续性
- GREEN23｜质量、体积与拟态尺度边界
- GREEN24｜载具功能、乘员与伪装表现
- GREEN25｜战斗变形、受损变形与重新扫描

## 职责边界检查

### GREEN21

PASS。只负责扫描信息、模板兼容与技术复制边界。已明确扫描外形不等于获得目标的特殊武器、材料、能源核心或算法。

### GREEN22

PASS。只负责基础形态与替代形态的连续结构映射、折叠、锁定与中间形态。没有把变形写成瞬移或新身体生成。

### GREEN23

PASS。只负责质量、体积、密度和拟态尺寸的合理边界。允许赛博坦级结构压缩，但不建立无限 mass shifting，也不把体型直接等同综合战力。

### GREEN24

PASS。只负责载具形态的真实机械功能、乘员空间、共享控制与伪装表现。乘员能够驾驶不等于拥有身体支配权，与 GREEN05 的共处边界一致。

### GREEN25

PASS。只负责战斗中的连续变形、伤势影响、强行变形风险与重新扫描。已明确重新扫描不能治疗旧伤，也不能重置机体等级、人格或历史。

## 跨条目一致性审计

PASS。

- GREEN21 与 BLUE05 的扫描边界一致，不建立“看一眼就复制黑科技”的漏洞。
- GREEN22 与 GREEN08 的活体机械组织一致，变形是同一身体的重排，不取消疼痛和损伤。
- GREEN23 与 BLUE06 保持职责分离：尺寸影响物理表现，但综合战力仍由多变量决定。
- GREEN24 与 GREEN05 保持一致：载具形态仍是本人身体，乘员操作属于双方允许下的共享控制。
- GREEN25 与 GREEN09 保持一致：变形和重新扫描不能替代维修医疗。
- 本组没有引入无限质量变化、自动修复、瞬间传送式变形或扫描万能复制。

## 关键词审计

PASS。

- 不使用 `扫描`、`变形`、`载具` 等单个过宽裸词作为唯一正式触发词。
- GREEN21-GREEN25 使用多词组语义关键词，尽量降低同组误触。
- `active_green_entries.keywords` 继续作为正式装配时唯一有效关键词来源。

## 视觉与动作审计

PASS。

本组保留《变形钢姬》的核心机械视觉：变形由真实结构在高速运动中连续折叠完成；战斗中可以利用中间形态，但伤势、锁定失败与结构负荷同样真实存在。替代形态不是皮肤切换，而是完整的第二种身体姿态。

## 结论

BLUE05 已完成第一轮正式绿灯展开。

本轮不修改 BLUE01-BLUE08 正文，不提前展开 BLUE06 的综合战力判定。
