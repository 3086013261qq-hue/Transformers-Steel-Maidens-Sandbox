## 2. 格式

28条均使用咩咩原生人类 `chara-v1` 字段：

`名字 / 性别 / 印象 / 发色 / 发型 / 瞳色 / 身材 / 胸部 / 上衣 / 下装 / 配饰 / 鞋子 / 心理模型 / 人际关系 / 对话范例`

全部满足：

- `Trauma / Defense / Trigger / Need` 四槽齐全；
- 字段顺序严格为 `心理模型 → 人际关系 → 对话范例`；
- 三句对话范例齐全；
- 未使用赛博坦专用 `头部主色/机体比例/性征武装模块` 等字段；
- 未为人类建立赛博坦式能力条目。
