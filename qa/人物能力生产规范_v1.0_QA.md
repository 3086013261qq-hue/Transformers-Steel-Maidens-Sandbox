# 《变形钢姬》人物/能力生产规范 v1.0 QA

状态：PASS / FORMAT_LOCKED

## 核验目标

确认《变形钢姬》人物与能力生产不另造 schema，而是在咩咩制卡包·全栈 v1.0.0 的原生格式上做赛博坦语义适配。

## 角色条目核验

PASS。

固定结构保持：

`名字 → 性别 → 印象 → 发色 → 发型 → 瞳色 → 身材 → 胸部 → 上衣 → 下装 → 配饰 → 鞋子 → 心理模型 → 对话范例`

无新增“核心信念 / 人格层 / 行为逻辑 / 能力 / 技能”等栏位。

## 心理模型核验

PASS。

严格保留且固定顺序：

1. Trauma
2. Defense
3. Trigger
4. Need

未改写为赛博坦术语；四槽用于心理因果链，不用于机体参数或战斗属性。

## 赛博坦字段适配核验

PASS。

- 发色：保留字段名，改写为毛发缺失/机械缆线或头部装甲颜色。
- 发型：保留字段名，改写为头冠、头部装甲轮廓、天线、鳍片、缆线/须状结构。
- 瞳色：光学镜颜色/数量/形态。
- 身材：承载身高、质量/体重、机体规格与女性机体比例。
- 胸部：保留字母罩杯等效视觉体量，并写胸甲/活体机械结构。
- 上衣/下装：保留字段名，内容改为上下半身装甲与载具零件布局。
- 配饰：徽记、面罩、天线、轮组、外置工具等。
- 鞋子：足部装甲、轮组、履带、抓地/起落结构。

没有凭空为赛博坦人制造人类毛发、布制服装或独立鞋具。

## 能力条目核验

PASS。

- 能力不进入 `chara-v1`。
- 统一使用 `<核心设定:角色名·能力>...</核心设定:角色名·能力>`。
- 能力正文允许按角色自然组织，不自创第二套世界书 schema。
- 专属性征武装、变形、常规武装、特殊权限、能耗、热负荷、损伤与限制都在能力条目解决。

## 人物生产硬要求

PASS。

- 女性角色继续保留身高、质量/体重、罩杯字母等体格锚点；在 `身材` / `胸部` 原生字段中承载，不新增字段。
- 三句对话范例保持咩咩原生要求。
- 正式人物正文只用娘化名。
- 原名仅作工程检索与时间线替换键。

`docs/002_变形钢姬_咩咩全栈人物条目与能力条目生产规范_v1.0.md` 可作为后续 69 名人物与能力条目的唯一生产格式基线。
