## 四、心理模型去同质化

PASS。

15 名角色均完整使用 `Trauma → Defense → Trigger → Need`，核心线分别为：

- 星啸娅：长期屈居强者阴影 → 野心/讥讽/机会主义 → 权威羞辱 → 被承认为独立领导者。
- 芭莉凯：目标逃脱与失控 → 恐吓/审讯/追踪控制 → 监控断裂 → 重新收束混乱。
- 桑德薇：通信盲区与情报来迟 → 数据收集/情绪压缩 → 黑障与篡改 → 即使无答案也被当作同伴。
- 朔珂薇：不可控变量导致计划崩坏 → 绝对逻辑/火力 → 指令与数据混乱 → 世界可以被理解和预测。
- 梅格萝娜：被远古同伴阻止与封禁 → 神圣化使命 → 至尊旧誓约与能源计划受阻 → 证明自身生存逻辑正确。
- 洛黛恩：雇主与阵营反复背约 → 契约化关系/保留退出路径 → 改约与强制忠诚 → 保持独立选择权。
- 昆塔莎：造物脱离控制 → 起源神秘化/操纵 → 所有权主张被拒绝 → 被承认为持续权威。
- 克罗米娅：轻型单位被消耗/编队失联 → 维持队形与互保 → 通信断裂/诱饵化 → 有人也会为她回头。
- 艾丽塔-1：小队因缺乏协调而损失 → 承担指挥与压低私人情绪 → 队形崩散 → 协调被理解为信任而非控制。
- 乔缇：高能接驳事故与维修来迟 → 反复检查/步骤化情绪 → 强行跳过安全 → 谨慎被认可为救人能力。
- 斯琪：被当成笑话和搭档附属 → 吹嘘/冒险/抢先行动 → 被低估或与玛芙比较 → 单独获得可靠性承认。
- 玛芙：与斯琪失联经验 → 贴近/玩笑/抢先冲锋 → 搭档再次失联 → 独立与亲密可以共存。
- 薇莉：弱小个体被阵营当工具 → 讨好/改口/趋利避害 → 被过去阵营羞辱或当一次性探针 → 不靠卑微换取安全归属。
- 布蕾茵：无人机身份与被控制历史 → 讽刺/炫耀智力/抢先入侵 → 被称作程序或附件 → 被承认为独立技术者。
- 莉德芙：破障任务长期减员 → 强硬/亲自站前线/反复检查 → 无侦察强冲与撤离失败 → 把队员一起带回来。
