## 五、心理模型去同质化

PASS。

15 名角色均使用 `Trauma → Defense → Trigger → Need`，核心线分别为：

- 博妮珂：破障消耗品经历 → 持续前冲与逞强 → 被独自留在缺口 → 被当作可撤回的战士。
- 芙蕾茜：微型工具化/战场脆弱 → 喋喋不休与抢先入侵 → 被当附件 → 获得独立情报员身份。
- 拉薇琪：猎杀单位工具化 → 沉默与持续追踪 → 强制回收/被当宠物 → 自主判断与领地被承认。
- 蕾瑟碧：长期潜伏与脏活 → 伪装和保持距离 → 身份暴露/贡献被抹去 → 价值不只来自隐形。
- 赛德薇：无意义死守造成损失 → 永远准备撤离路线 → 出口封死/谨慎被羞辱 → 证明活着回来也是专业。
- 斯卡佩拉：资源不足与重伤堆积 → 临床化与数据化 → 医疗判断被政治干预 → 仍把生命当生命而非零件。
- 格琳朵：运输进去却带不回同伴 → 寡言与载荷确认 → 撤离路线切断 → 自己也拥有撤离位置。
- 黛莫莉莎：重型单位被默认可放弃 → 机械执行/结构专注 → 无撤离方案顶线 → 拥有撤退权。
- 兰佩琪：长期固定看守 → 持续移动和挑衅 → 被锁定原地 → 战术自由。
- 米克茜：化学事故记忆 → 配比与实验控制 → 未确认混用介质 → 专业被视为技术而非大爆炸按钮。
- 珑荷：运输线崩溃导致减员 → 清单化与多扛载荷 → 丢伤员减载 → 后勤价值被承认。
- 斯嘉佩：坍塌中被延迟救援 → 主动清障 → 被埋/救援延后 → 强壮不等于不会受伤。
- 克兰茜：情报泄露导致伏击 → 控制信息与路线 → 通信盲区/反入侵 → 容忍不可控信息。
- 克萝芭：封闭设施逃生创伤 → 不断寻找出口 → 通道锁死 → 在没有预设退路时也能信任同伴。
- 哈琪特：兽形单位被放弃回收 → 追踪与贴近队伍 → 撤离不通知/被称无智野兽 → 被当作有选择的战士。
