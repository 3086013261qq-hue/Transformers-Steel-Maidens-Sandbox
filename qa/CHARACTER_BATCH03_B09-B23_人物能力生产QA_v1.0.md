## 五、心理模型去同质化

PASS。

15 名角色均完整使用 `Trauma → Defense → Trigger → Need`：

- 路芭：破障减员/火力不足 → 提前堆火力与嘴硬 → 火力死角/撤离受阻 → 用火力让队友活着回来。
- 托璇：结构坍塌困住同伴 → 检查与拆解控制感 → 跳过工程安全 → 让谨慎被视为生存价值。
- 斯奎琪：残损与被低估 → 逞强抢任务 → 被替她决定“不行” → 作为真正队员承担风险。
- 柯曼妮：保护职责失败恐惧 → 完美礼节与环境控制 → 护卫程序被无视 → 忠诚被承认为主动选择。
- 卡诺霏：难民和平民被战争吞没 → 自我压低/站最前面 → 平民无掩体与撤离受阻 → 保护者也会被带走。
- 黛翠：资源匮乏导致不可逆损失 → 把情感包装成交易 → 浪费与强抢资源 → 让回收真正延续生命。
- 特伦茜：工程失误造成坍塌 → 测量与反复确认 → 无勘测强施工 → 慢一点把结构做对也有价值。
- 布尔妲：漫长岁月与记忆磨损 → 老规矩和固定巡逻 → 口令被无视/记忆断裂 → 老兵仍值得尊重。
- 莉妲：大量飞行员未归航 → 计算航线与返航窗口 → 强行起飞/浪漫化牺牲 → 安全返航同样是荣誉。
- 斯蕾芙：被当作双头飞行兵器 → 持续巡视/双向监控 → 强制统一控制 → 双重感知也属于完整自我。
- 斯露琪：被当成冲锋工具 → 主动选择冲锋方向 → 强制撞阵/控制装置 → 力量与判断同时被尊重。
- 斯蔻恩：被定义为危险拆迁巨兽 → 夸张破坏与持续移动 → 封闭拘束 → 自主决定力量的用途。
- 布莱蔻：突袭中被反定位围猎 → 抢先压制感知 → 电子战反制/行踪暴露 → 掌握进入战场的节奏。
- 斯珂琶：长期作为追踪工具 → 隐蔽与保留退路 → 被迫暴露/无条件追击 → 自主决定何时猎杀与撤离。
- 布萝尔：重装机体被当消耗品 → 怒吼、火力与主动顶前线 → 重伤仍被要求推进 → 被承认有痛觉与判断。
