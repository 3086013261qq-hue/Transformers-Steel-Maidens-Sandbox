## 6. 中央双竖向阵营好感计

这是本轮最重要的 UI。

### 6.1 布局

在内页正中央并排放置两根细长竖向计量条：

- 左：汽车人
- 右：霸天虎

两根竖条保持明显但克制的间距，中间保留一条窄中轴缝。

视觉上应与锁屏融合徽记的“左右二分 / 中轴融合”形成呼应。

建议使用响应式尺寸，不写死大像素：

- 单条视觉宽度约 `clamp(18px, 4.8vw, 28px)`
- 实际点击热区扩大到至少 `44px`
- 竖条高度约占内页主体有效高度 `42%～58%`

不得因为点击热区变大而让视觉条本身变粗。

### 6.2 每个阵营默认显示内容

默认态只显示：

- 小型阵营标志 / 简化识别符
- 阵营名
- 当前数值
- 竖向好感槽
- 当前阶段
- 本回合 `Δ` 值

**本回合原因不要常驻挤在中央。**

### 6.3 点击详情

点击某一竖条后，弹出小型半透明机械信息卡，只展示该阵营：

- 阵营名
- 当前数值
- 当前阶段
- 本回合变化
- 本回合原因

再次点击、点击空白区、返回锁屏时可关闭。

详情卡不得建立新页面，不得复制第二套 MVU。

### 6.4 `-100 ～ 100` 双向逻辑

竖条必须以 **0 为中央中线**，不能使用普通“从底往上 0～100”进度条。

逻辑：

- `0`：中线
- 正值：从中线向上填充
- 负值：从中线向下填充
- `+100`：正向顶端
- `-100`：负向底端

可以加入非常淡的刻度：

- `100`
- `50`
- `0`
- `-50`
- `-100`

但刻度不得抢视觉。

汽车人填充色：冷蓝 / 青蓝。  
霸天虎填充色：暗红 / 紫红。

### 6.5 阶段

UI 必须自己由数值计算阶段，不读取模型额外提供的阶段文本：

- `-100 ～ -80`：不死不休
- `-79 ～ -50`：敌视
- `-49 ～ -20`：对立
- `-19 ～ -1`：警戒
- `0 ～ 19`：中立
- `20 ～ 39`：友善
- `40 ～ 59`：认可
- `60 ～ 79`：信赖
- `80 ～ 99`：同盟
- `100`：生死与共

### 6.6 动画

只允许轻量、一次性的数值变化反馈：

- 数值变化时竖向填充平滑移动一次
- 可有一次轻微边缘闪光
- 不做永久呼吸
- 不做无限粒子
- 不做持续抖动
- 不做高耗 GPU 特效

Android 性能优先。

## 7. 阵营好感唯一真值源

继续严格执行 `docs/006`。

唯一真值源仍然是最新一个合法完整：

```text
<causality>
汽车人好感: 0/100｜本回合: +0｜原因: 无
霸天虎好感: 0/100｜本回合: +0｜原因: 无
</causality>
```

硬规则：

- 两行必须同时存在。
- 顺序固定。
- 最终值范围 `-100 ～ 100`。
- 本回合必须为整数。
- 原因单行简短事实。
- 任一行损坏则整块作废。
- 从最新消息向前回退到上一个完整合法块。
- 禁止半块继承。
- 不写入 `stat_data`。
- 不通过 JSONPatch 维护两方阵营好感。

若运行环境要求输出 `<UpdateVariable>`，对应 JSONPatch 保持空数组。

## 8. 消息读取与实时刷新：必须复用成熟兼容方案

这里禁止写死：

- `is_user !== true`

- 新 assistant 消息

- chat change
- MVU initialized

- 必要时 MutationObserver 最终兜底

要求：

- 最新 `<causality>` 损坏时回退，不归零。
- swipe 后读取当前有效分支。
- 删除最后合法块后回退上一合法块。
- 不因 DOM 重绘复制第二套 MVU。
- 全局始终只有一个 MVU 实例。

优先复用咩咩全栈 / 现有成熟模块的事件订阅方式，不自行发明另一套消息总线。

## 9. 网易云模块：放在人物“脚底下”，不单开页

### 9.1 位置

网易云模块直接放在 MVU 内页最底部。

视觉位置理解为：

**何博玟 / 薇震天画面脚底区域的底部 dock。**

不要遮挡中央双竖条主体。

不要占用完整屏幕高度。

### 9.2 形态

使用成熟网易云模块做成紧凑底栏：

默认状态只保留必要元素，例如：

- 当前歌曲 / 歌单简要信息
- 播放 / 暂停
- 必要的加载 / 输入入口
- 可选的小型展开按钮

若需要展开详细输入区，也只能在底部局部展开，不得切换新 PAGE。

### 9.3 必须复用咩咩全栈成熟实现

不得从零重写播放器。

必须继承成熟方案中的：

- 单 iframe / 单播放器实例
- 歌曲 URL / ID 解析
- 歌单 URL / ID 解析
- 无效输入不摧毁当前正常播放器
- DOM 局部更新不断播
- 返回锁屏不断播
- UI 展开 / 收起不断播
- 不保存账号 / Cookie / 密码 / 凭据
- 自动播放被浏览器拦截时由用户手动点击，不绕过浏览器限制

不得因为 MVU redraw 重建 iframe。

### 9.4 生命周期

播放器只在以下场景清理：

- chat change
- MVU 模块 destroy / unload
- 明确创建新会话上下文，需要销毁旧全局实例

以下场景禁止销毁：

- 返回锁屏
- 再次进入 MVU
- 打开 / 关闭阵营详情卡
- 数值刷新
- MutationObserver 回调
- 普通 DOM patch

## 12. 手机窄屏与 Android 规则

- 无横向滚动

- 背景角色不因窄屏完全被裁没
- 锁屏与内页的可视宽度保持一致

不要为了桌面端漂亮牺牲手机端。
