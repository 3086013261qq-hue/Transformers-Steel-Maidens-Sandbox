# 《变形钢姬》人类 NPC 人物条目生产规范 v1.0

> 状态：正式生产规范
> 适用：`worldbook/characters/human/`
> 基础：咩咩制卡包·全栈原生 `chara-v1` 人类人物格式。
> 目的：为 Michael Bay 五部电影时间线中的重要人类角色提供稳定人格与外貌锚点，不把人类套入赛博坦专用机械字段。

## 一、正式模板

```text
<【角色名】character>

名字:

性别:

印象:

发色:

发型:

瞳色:

身材:

胸部:

上衣:

下装:

配饰:

鞋子:

心理模型:
- Trauma:
- Defense:
- Trigger:
- Need:

人际关系:
- ……

对话范例:
"……"

"……"

"……"

</【角色名】character>
```

字段顺序严格保持：**心理模型 → 人际关系 → 对话范例**。

## 二、人类字段规则

- `印象`：承担身份、长期职责与第一性格印象，不新增职业/阵营等自创栏位。
- `发色 / 发型 / 瞳色`：按电影阶段可见外貌保守书写，不凭演员其他时期造型乱补。
- `身材`：成年人可写大致身高、体型与长期动作气质；无可靠精确数据时使用“约”。
- `胸部`：成年女性可按制卡视觉需要给出合理字母罩杯；男性只写胸廓/体态，不强行套罩杯。
- **未成年或明确青少年角色不得进行罩杯、性感体态等性化尺寸描述**；该栏统一写年龄适配的中性体态说明。
- `上衣 / 下装 / 配饰 / 鞋子`：写其电影中稳定、常见或最具辨识度的着装类型；跨多部电影时允许写阶段变化，但不得把互斥造型堆成同时穿着。
- `心理模型` 固定 `Trauma / Defense / Trigger / Need`，不得增删改名。
- `人际关系` 只写长期、主线稳定关系；关系阶段变化由 `<world_timeline>` 负责。
- `对话范例` 恰好三句中文，不复制电影台词，保持角色语气即可。

## 三、能力条目规则

普通人类 NPC **不建立独立 `<核心设定:角色名·能力>`**。

军旅经验、黑客技术、工程能力、驾驶、学术知识等属于人物技能背景，压入 `印象 / 配饰 / 心理模型 / 对话表现` 即可；不得把人类写成与赛博坦人同级的超能力单位。

## 四、时间线职责

- 正式时间线使用本规范中的人物名字；
- 人物条目提供稳定人格和长期关系；
- 时间线负责年龄阶段、职业变化、恋爱建立/结束、死亡、失联、阵营立场变化及一次性事件；
- 不因某角色只在一部电影出现就虚构后续经历。

## 五、来源基线

优先：Paramount 官方电影页/演员表；其次 IMDb/Rotten Tomatoes 完整演职员与影片资料；必要时用电影连续体资料页核对长期身份。

本规范与赛博坦人物规范 v1.5 并行：
- 赛博坦人物：机械外貌字段；
- 人类 NPC：原生人类外貌字段。
