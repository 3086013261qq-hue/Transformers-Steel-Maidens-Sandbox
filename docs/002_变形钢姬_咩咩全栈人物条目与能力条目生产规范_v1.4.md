# 《变形钢姬》咩咩全栈人物条目与能力条目生产规范 v1.4

> 状态：审计后正式生产规范
> 基础格式：继承 v1.3 全部角色字段、机械外貌字段、心理模型与 GitHub Preview 排版规则。
> 当前人物上游：`docs/001_变形钢姬_人物总名册_v0.4.md`
> 目的：在不改变咩咩 `chara-v1` 心理/人格骨架的前提下，锁定上游事实与工程资料的职责边界，并统一能力条目完整度。

正式人物条目继续严格使用：

```text

- Trauma:

"……"

```

`Trauma / Defense / Trigger / Need`、三句对话、机械外貌字段与空行格式全部沿用 v1.3，不得改名、删减或恢复人类发型/服装字段。

## 二、人物总名册仍是五项上游真源

角色条目以下五项必须从现行人物总名册直接继承：

`阵营 / 定位 / 变形载具 / 外貌锚点 / 性征武装模块`

其中：

- `外貌锚点` 必须逐字一致；
- 其他四项不得在人物条目中私自创造第二套业务事实；
- 若发现上游字段本身错误，必须先修人物总名册，再同步下游人物条目与能力条目。

## 三、业务字段与工程资料必须彻底分离

从 v1.4 起，五项继承字段只允许写**世界内可成立的业务事实**。

禁止直接出现在继承字段中的工程措辞包括但不限于：

- `电影未展示`；
- `官方玩具确认`；
- `概念图/衍生资料`；
- `AU 制卡估算`；
- `基于原作/娘化/原男性`；
- 任何只用于说明证据等级、资料来源或制作决策的元叙事。

这些信息统一进入人物总名册的“工程资料注记”、QA、来源清单或 research 文档；不得被正式 worldbook 人物条目继承。

## 四、质量、尺度与组合形态硬规则

所有人物能力与变形载具必须遵守 BLUE05 / GREEN21-GREEN25，尤其 GREEN23：

- 单个小型机体不能无条件变成远超自身质量/体积的完整大型载具；
- 组合载具必须说明参与个体与质量来源；
- Headmaster / 宿主接驳必须区分“小型个体自身”与“兼容宿主体/载具系统”；
- 资料中存在的玩具载具方案若与正式 AU 机体尺度冲突，只能留作工程参考，不得强行进入正式个人变形能力；
- 扫描、重新拟态、Transformium 重排都不能凭空治愈伤势或免费创造质量。

## 五、能力条目语义完整度

能力条目仍使用：

`<核心设定:角色名·能力> ... </核心设定:角色名·能力>`

不强制固定小标题，也不按字数机械验收，但每条必须在语义上覆盖其适用项：

1. **机体/替代形态**：体型、底盘、载具或特殊结构为什么构成优势；
2. **性征武装**：展开方式、主要用途、控制或拆离边界；
3. **常规武装/辅助系统**：有则说明，与性征武装区分；
4. **战斗/工作方式**：角色如何把能力组合成真实战术或职业能力；
5. **资源约束**：Energon、热负荷、弹药、润滑、接口、处理能力、距离等至少覆盖实际相关项；
6. **损伤反馈**：关键结构受损会怎样降低能力；
7. **明确不可做之事**：避免把黑客、维修、遗产、变形、飞行、控制等能力写成万能权限。

不相关的维度无需硬塞，但不得只写“武器是什么 + 一个弱点”就结束。

## 六、特殊生命来源必须说明连续性

对于 KSI、人工构筑、分裂体、重构体等非典型个体，能力条目必须明确：

- 身体由谁/如何制造，不自动等于人格由制造者拥有；
- 独立火种或人格连续性何时成立；
- 复制设计、生产数据、备份或同型机体不能自动等同原个体；
- 分裂多体若共享一枚火种，必须说明总质量、总能量、伤害反馈与意识关系。

不得从个别角色的特殊起源推导“所有同类量产单位自动具有完整火种”。

## 七、正式名称与时间线

- 文件名、人物标签、`名字:`、能力标签及正式剧情只使用娘化名；
- 原名仅用于工程检索、来源核对和 `character-name-replacements.v1.json` 的替换键；
- 正式 `<world_timeline>` 输出必须完成原名 → 娘化名替换。

## 八、审计后生产检查

角色/能力进入正式层前至少检查：

1. 人物编号与人物/能力文件一一配对；
2. 五项上游字段与当前 roster 一致；
3. 外貌锚点逐字一致；
4. 无工程元叙事污染正式人物正文；
5. 心理模型四槽完整且形成因果链；
6. 三句对话存在；
7. 能力满足第五节的语义完整度；
8. 质量、尺度、能量、损伤和变形规则不与 BLUE/GREEN 冲突；
9. 非典型生命来源有明确火种/人格连续性说明；
10. 原名未作为正式角色显示名重新进入 worldbook。

## 九、版本结论

v1.4 不改变 v1.3 已封版的人物格式与心理模型；本次只新增并强化：

- 工程资料与业务字段分离；
- 质量/尺度/组合/Headmaster 规则；
- 能力条目语义完整度；
- 非典型制造生命的人格连续性要求。

后续人物层、关系层与时间线生产以 v1.4 + 人物总名册 v0.4 为唯一现行基线。
