# 《变形钢姬》人物总名册 v0.4

> 状态：人物层总拉通审计后正式基线
> 基线：Michael Bay 五部电影《变形金刚》(2007)、《卷土重来》、《月黑之时》、《绝迹重生》、《最后的骑士》
> 设定层：沿用 `SETTING_LAYER_COMPLETE`，全员女性赛博坦人且普遍具有双重性征。
> 命名层：沿用 v0.2 已审定娘化名；`manifest/character-name-replacements.v1.json` 继续作为时间线原名→娘化名替换基线。
> 说明：本文件中的「扶她武器模块」在正式世界书术语中对应「性征武装模块」；只定义非露骨的生体机械武装形态，不展开亲密行为。

## 录入与时间线替换原则

1. `原名映照` 只承担资料检索、原作核对、事件对齐与替换键功能；正式剧情输出不得继续使用原名。
2. 正式 `<world_timeline>`、事件标题、正文和参与者字段必须执行：`原作中文名 / English Name / 其他别名 → 娘化名`。
3. 多别名同一生命连续体汇聚为同一娘化名，例如：`Megatron / Galvatron → 薇震天`、`Dino / Mirage → 米拉琪`、`Que / Wheeljack → 薇尔嘉`。
4. `变形载具 / 形态` 只写正式世界内可成立的业务事实；电影镜头、官方玩具、概念图、衍生资料等来源等级统一放到工程资料注记，不得混进会被人物条目继承的业务字段。
5. `定位` 只写长期稳定职责、战斗风格或组织角色，不把“某一场战斗做过什么”写成终身职业。
6. `外貌锚点` 只保留 1～2 个电影视觉中最容易一眼识别的结构；完整外貌留到人物卡逐角复核。
7. `扶她武器模块` 必须与角色机体、原作战斗气质和 AU 性征武装规则同时兼容；并非所有模块都必须拆离。
8. 武器类型保持显著多样化：允许少数角色使用主炮，但总体覆盖刃、枪、戟、锤、鞭、链、弓、弩、钩、爪、锯、钻、医疗器械、电子战接口、拘束与工具型武装。
9. 原作本就以女性身份出现的 Arcee、Chromia、Elita-One、Quintessa 沿用正式名。
10. Devastator、Dragonstorm、Infernocus 等组合体以及无名 Protoforms / KSI Sentries / Shadow Raiders 等群体单位不占独立人物卡名额；需要时另建 group/composite 条目。
