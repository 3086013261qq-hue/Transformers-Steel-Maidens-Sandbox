# 《变形钢姬》worldbook/locations 地点层

## 定位

本目录是《变形钢姬》正式地点世界书源。地点条目只负责“当前身处某地时，AI应知道这里是什么、有哪些空间/阵营/风险/可互动资源，以及在当前剧情阶段哪些事实已经成立”。

地点条目不负责推进剧情，不替代 `<world_timeline>`，也不因为玩家抵达某地就自动宣告该地点未来事件已经发生。

## 咩咩全栈正文格式

每个正式地点正文使用：

```text
<核心设定:地点名>
归属:
类型:
环境:
正常功能:
时代状态:
势力:
关联人物:
剧情锚点:
知识边界:
RP场景:
互动约束:
</核心设定:地点名>
```

原则：

- 正文优先服务 RP，不写旅游百科式堆料。
- “时代状态”允许同一地点跨 MAIN 更新，但只能依据当前已经发生的时间线事实。
- “知识边界”必须阻止普通 NPC、早期角色或玩家在未触发剧情前提前知道后作秘密。
- 城市条目只写城市层事实；子设施条目只写设施层事实，避免复制。
- 电影自身未解释的空白保持“未知/未确认”，不得自行补完。

## 灯色与触发

所有具体地点条目均为 **绿灯 / keyword_triggered**，不做常驻蓝灯。

正式装配时触发必须锚定 `<status>` 中的 `当前位置:`，推荐：

```regex
/<status>[\s\S]*?当前位置:[^\n<]*(?:地点全称|简称|必要别名)[\s\S]*?<\/status>/s
```

不得使用普通聊天正文中的地点名作为独立触发来源，否则角色随口提到“芝加哥”就会误加载整条地点设定。

绿灯地点条目装配属性：

- `always_on=false`
- `keyword_triggered=true`
- `prevent_recursion=true`
- `exclude_recursion=true`

## 粒度

- A级：长期核心、跨卷重复或高频 RP 地点。
- B级：电影主舞台、重要战区、大型剧情地点。
- C级：设施子区域、交通空间、短时特殊地点或伏笔研究区。

正式候选总名册见：`docs/005_变形钢姬_地点总名册_v0.1.md`。
