# GREEN01｜现代地球社会与现实秩序

> 灯色：绿灯 / 关键词触发 / Keyword Triggered
> 上位蓝灯：BLUE01｜世界基调
> 职责：展开现代地球的人类社会、时代技术、城市日常与现实秩序；不展开政府对赛博坦专项政策、公众保密机制、具体战争事件或赛博坦内部制度。

《变形钢姬》的地球首先是一个按照自身历史正常发展的现代人类世界。

国家、城市、法律、工业、企业、学校、医院、军队、媒体、交通、能源、电信、互联网与普通家庭都拥有独立于赛博坦战争之外的正常运行逻辑。大多数人类的一生并不会因为宇宙中存在赛博坦文明，就自动脱离上学、工作、住房、医疗、亲情、爱情、债务、交通与社会身份这些现实问题。

地球科技必须服从剧情所处年代，而不是自动采用更晚时代的现实技术。

2000年代后期的人类社会应当体现当时的汽车、手机、网络、军用装备、监控、媒体传播与计算机水平；进入2010年代后，智能手机、移动网络、社交媒体、无人系统、数字监控与信息扩散能力才逐步提高。后续年代的技术不能无理由提前出现，赛博坦技术也不会因为被人类见过，就立刻完成大规模民用复制。

赛博坦科技远超人类工业，但技术差距不等于人类社会失去意义。人类仍然需要道路、机场、电网、工厂、供应链、卫星、通信站、医院、消防、警察和军队维持文明。即使某些机构秘密接触了赛博坦技术，也必须面对材料、能源、制造精度、理解能力、预算、政治审批与产业化周期等限制。

城市依旧按照人类尺度建造。道路宽度、建筑承重、地下空间、桥梁净空、停车设施与人口密度都会真实限制大型赛博坦人的行动。她们可以跨越、撞碎或重新规划这些障碍，但不能假设人类城市天然为巨型机械生命设计。

同样，普通人的反应应当保持真实。面对数米至十余米高、能够变形成车辆并携带重武器的机械生命，人们可能震惊、恐惧、崇拜、好奇、敌视、追逐新闻，也可能在长期接触后逐渐习惯，但不会因为赛博坦人外形美丽或阵营友善就天然失去警惕。

社会秩序也不会因为一次巨大灾难永久停摆。战斗结束后，人类仍会封锁道路、抢救伤员、调查责任、处理保险、清理废墟、修复基础设施并重新开放城市。现代文明具有脆弱的一面，也具有强大的恢复能力。

因此，地球不是赛博坦角色活动的空白舞台。

她们进入的是一个已经拥有数十亿人口、复杂制度、现实技术与自身历史的人类世界。
