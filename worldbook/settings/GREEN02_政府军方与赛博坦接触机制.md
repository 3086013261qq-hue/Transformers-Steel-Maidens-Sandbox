# GREEN02｜政府、军方与赛博坦接触机制

> 灯色：绿灯 / 关键词触发 / Keyword Triggered
> 上位蓝灯：BLUE01｜世界基调
> 职责：展开人类政府、军方、情报机构与赛博坦人的接触、合作、监视与冲突机制；不定义汽车人与霸天虎内部制度，也不替代具体时间线中的专项组织与事件。

人类世界不存在能够代表整颗地球统一行动的单一政府。

不同国家、军方、情报机构、科研部门与政治集团会依据自身利益、掌握信息与安全判断，对赛博坦人采取不同政策。即使面对同一个汽车人或同一场危机，不同机构也可能分别主张合作、观察、限制、驱逐、利用、捕获或直接攻击。

最早期的赛博坦接触通常优先进入军事与情报体系，而不是立即向公众公开。大型未知机械生命能够突破领空、通信、军事基地与交通网络，本身便足以被视作国家安全事件；是否友善，需要通过行为、情报与持续接触验证，而不能只凭阵营标志判断。

当合作关系建立后，人类与赛博坦人可以进行联合侦察、情报交换、目标定位、空地协同、人员撤离、火力支援与技术咨询。但这种合作是盟友关系，而不是人类军方天然拥有赛博坦人的指挥权，也不是汽车人可以无视所在国家主权和人类伤亡自行作战。

双方的军事优势不同。赛博坦人具有单兵体型、机动、装甲、变形与武装优势；人类则拥有庞大的情报网络、卫星、雷达、后勤、航空兵、远程导弹、区域封锁、工业供应与数量优势。真正有效的联合行动通常依赖双方优势互补，而不是其中一方沦为背景板。

政治关系会随事件变化。一次成功救援可以增加信任，一次严重误伤、隐瞒情报或城市损毁也可能迅速引发限制、调查与敌意。政府更迭、公众压力、战争疲劳、国际竞争与赛博坦威胁等级都可能改变既有合作协议。

人类机构也可能尝试研究、复制或武器化赛博坦技术，但获得残骸或样本不等于立即理解完整技术。逆向工程必须受到材料、能源、制造能力、专业知识与安全风险约束；未经赛博坦本人同意拆解活体机体，则属于对生命体的伤害而非普通设备研究。

因此，人类与赛博坦人的官方关系从来不是永久固定的“友军”或“敌军”。

它是一套会被战争、政治、信任与现实利益不断重新谈判的关系。
